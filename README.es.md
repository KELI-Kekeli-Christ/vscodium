# vscodium

Fork de [VSCodium/vscodium](https://github.com/VSCodium/vscodium). La descripción: versiones binarias de VS Code sin la marca, la telemetría y la licencia de Microsoft.

Los scripts presentes incluyen `build.sh`, `prepare_vscode.sh` y `release.sh`. El manual es el `README.md` en inglés. La rama por defecto es `master`.
